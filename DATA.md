## Reuse terms (checked 2026-11-10)
- **Site-wide statement:** <https://www.rijksoverheid.nl/copyright> says the website is covered by the
  Creative Commons zero declaration (**CC0 1.0**), so texts may be reused without permission.
- **Exceptions named on that page**, and how this project handles them:
  - Texts explicitly marked as copyrighted may not be reused → every page's own
    `DCTERMS.rights` meta tag is read during ingest, and only pages tagged
    `CC0 1.0 Universal` are kept (`ALLOWED_LICENSES` in `src/rag/ingest.py`).
  - Images and video are almost never reusable → we store **text only**; video blocks are
    dropped during parsing.
  - Reusers must make clear that the Rijksoverheid does not automatically endorse their work →
    see the disclaimer below and in the README.
- **robots.txt** (<https://www.rijksoverheid.nl/robots.txt>, checked 2026-11-10) allows all paths.
  The crawler identifies itself with a project User-Agent and waits 1 s between requests.
- The site's AI-use page (<https://www.rijksoverheid.nl/ai-gebruik>) describes how *their editors*
  use AI tools; it does not restrict reuse of the published texts.

## Disclaimer
This is an independent student project. The Rijksoverheid is not involved and does not
necessarily agree with any answer this system produces. Answers can be wrong or outdated;
always check the linked source page.

## Deliberately excluded
- **toeslagen.nl / belastingdienst.nl** (Dienst Toeslagen): the authoritative source for huur- and
  zorgtoeslag amounts, but their reuse terms have not been checked, so they are not included.
  rijksoverheid.nl pages on these topics often link there; questions whose answer is *only* there
  are good "unanswerable" eval cases.
- **duo.nl**: same reason (terms not checked).

## Notes for the eval
- Some pages exist for several years (e.g. `bedragen-kinderopvangtoeslag-2024`, `-2025`, `-2026`).
  They are kept on purpose: near-duplicate distractors make retrieval harder and more realistic.
- Pages can change. The eval runs on the committed snapshot `data/docs.jsonl`, not on the live site.
  Re-fetching (`uv run python -m rag.ingest --refresh`) may invalidate evidence quotes in
  `evals/questions.jsonl`; `check_labels` in the eval will report which ones.

## Labels for the answerability gate
- `evals/gate_questions.jsonl` (61 questions) plus the 51 reviewed questions in
  `evals/questions.jsonl` form the gate dataset (112 questions, 74 answerable, 38 unanswerable).
- Label = "a careful reader can answer this using only this corpus". Answerable questions carry
  the source URL and a verbatim evidence quote; `check_labels` verifies every quote.
- How the 61 new labels were made: Claude drafted them; a separate Claude pass checked every
  answerable question against the full source page and searched the whole corpus for every
  unanswerable one (57 correct, 4 unclear and rewritten). Karim then reviewed the full list with
  evidence ([docs/gate_questions_review.md](docs/gate_questions_review.md)) on 2026-11-17 and
  reported no errors, after which they were marked `reviewed`.
- Known bias: the questions were written knowing the corpus, so they are cleaner than real user
  questions. Unanswerable ones are deliberately near-domain (a missing year, amount or contact
  detail) plus a few off-topic ones.

## Reproduce
```bash
uv run python scripts/discover_sources.py   # optional: regenerate the URL list
uv run python -m rag.ingest                  # fetch missing pages + parse -> data/docs.jsonl
```
